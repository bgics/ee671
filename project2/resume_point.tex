		\item Developed pipelined hardware with shift registers, FIFOs, and Sobel core using $L_1$ norm approximation for efficient gradient magnitude calculation
		\item Implemented configurable threshold mechanism achieving binary edge detection with automatic min/max clipping
		\item Completed full VLSI design flow from RTL to physical design, achieving 0.663 ns setup slack, 51908.40 $\mu$m$^2$ area, and 23.15 mW power consumption
